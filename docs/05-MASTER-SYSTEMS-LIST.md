# Master Systems List — Everything Locked In

This is the complete high-level feature set we are designing toward.

### Core Combat & Progression (Original + Expanded)
- 5 original classes deeply expanded
- New classes: Beastcaller (morph), Artificer, Warden, Corsair, Voidwalker, Echo Knight, Plague Doctor
- Deep skill loadouts + Paragon
- Wide weapon variety + sockets + charms + rerollable Special Perks
- Instant PvP duels (loser loses nothing)

### Open World & Building
- Large continuous main planet with many biomes
- Fortnite-style building almost anywhere
- Living Bases + Base Spirits
- Meaningful weather and world events
- Player-made dungeons
- World Memory / Echo system

### Lifestyle Systems
- Pets (collection, bonding, strong passive boosts)
- Deep Fishing (300–500+ fish, special rods, aquariums)
- Hunting & Wildlife
- Tools (axes, pickaxes, etc.) for harvesting

### Social & Economy
- Grand Bazaar
- Night Market
- Soft reputation factions
- Player-driven economy

### Narrative / Soft Systems
- Fate Cards
- Pantheon of Forgotten Gods
- Dream & Nightmare Realms
- Collector’s Compendium
- Chaos Rifts
- Seasonal Mutations

### Space Frontier (New Core Pillar)
- Material gathering across the world
- Full spaceship construction and customization
- Active flight and space travel
- Infinite procedurally generated planets
- Alien life, resources, dinosaurs, metal planets, etc.
- Planetary outposts and multi-planet progression

---

## Design Priority Order (Recommended)

1. Solidify main world + building + tools + basic gathering
2. Pets + Fishing + Hunting (the fun lifestyle hooks)
3. Beastcaller + expanded classes
4. Spaceship construction + first planet jumps
5. Infinite planet generation + deeper space content
6. All the soft/narrative systems (Fate Cards, Gods, Dreams, etc.)

Everything is interconnected. Gathering feeds the ship. The ship feeds new planets. New planets feed better gear, pets, fish, and morphs. The loop never has to end.
