# Dionite Expanded Design Overview

**From dungeon ARPG → Living Open-World Sandbox**

### What Already Exists (kept)
- 5 strong classes with Diablo-style skill loadouts
- Biomes + procedural dungeons + bosses
- Deep loot (sockets, runes, gems, rarity)
- Paragon endgame
- Solid C++ architecture + iOS/Desktop targets

### What We’re Adding (the fun layer)

**World**
- True open world with many more biomes
- Fortnite-style building almost anywhere
- Vehicles and boats
- Dense, living wildlife

**Lifestyle Systems (major time sinks that feel great)**
- **Pets** — collect, bond, get powerful passive boosts (luck, gold, finds, capacity, etc.)
- **Fishing** — 300+ unique fish, deep rod system, many ponds/lakes per biome
- **Hunting** — track and harvest animals, feed into pets and morphs

**Classes**
- Original 5 stay
- New **Beastcaller** class that morphs into animals
- Additional classes (Artificer, Warden, Corsair) for more fantasy coverage

**Combat & Social**
- Many more weapon types (knives, bows, staffs, guns, etc.)
- Charms + highly variable Special Perks that can be rerolled (x60 luck, massive capacity, etc.)
- Instant PvP duels when players hit each other — loser loses nothing, winner gets gold + chance at extras

**Philosophy**
Everything should feel interconnected and rewarding. Fishing should make you rich. Pets should make you lucky. Building should make you feel at home. Morphing should feel powerful and expressive. Duels should be exciting and low-stress.

This is how we make a game that people don’t just play — they *live* in.
