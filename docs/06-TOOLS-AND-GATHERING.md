# Tools & Resource Gathering

## Design Goal
Gathering should feel satisfying and progressive, not like a chore. Better tools = dramatically better results and access to higher-tier materials.

### Tool Tiers
1. **Primitive** — wood/stone (early game)
2. **Common Metal** — iron/copper
3. **Refined** — steel, hardened alloys
4. **Crystal / Enchanted**
5. **Void / Cosmic / Planetary** (made from materials found on other planets)

### Special Tool Properties
Tools can roll:
- Higher yield
- Faster gathering
- Chance to double resources
- Chance to extract rare secondary materials
- Reduced durability loss
- Special Perks (same chaotic system as weapons)

A legendary pickaxe that sometimes yields pure gold from normal rock nodes is the kind of item players will chase.

### Resource Categories
- Wood (many species)
- Stone & Rock
- Ores & Metals
- Crystals & Gems
- Organic (fibers, resins, bones, hides)
- Exotic / Planetary (only from other worlds)

Some resources only appear after certain world events or on specific planet types.
